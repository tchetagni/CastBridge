### Progression des six leçons
1. **J'écoute et je reconnais** : associer ≥ 8 salutations lentes sur 10 à une image/situation ; écoute sans texte, puis avec texte, répétition guidée. ZH : entendre la différence entre tons sans les produire ; JA : rythme des morae ; DE : accent de *Guten Morgen*, initiale de *Hallo*.
2. **Je choisis le bon salut** : formule selon moment/familiarité ; ≥ 8 items de L1 ; association image-audio, discrimination de paires. ZH : 您好 forme polie en reconnaissance ; JA : おはようございます / こんにちは / こんばんは ; DE : *du* entre pairs, *Sie* avec inconnu/adulte.
3. **Je dis mon nom** : formule de présentation ; remettre les mots d'une réponse courte en ordre. ZH : 我叫… ; JA : わたしは…です (は = wa) ; DE : *Ich heiße…* (ei = /aɪ̯/).
4. **Je demande le nom** : comprendre la question, choisir la réponse ; écoute à l'aveugle, choix, jeu de rôle à trous. ZH : 你叫什么名字？ / 我叫… ; JA : お名前は？ ou お名前は何ですか。 ; DE : *Wie heißt du?* vs *Wie heißen Sie?* sans mélanger les registres.
5. **Je comprends l'échange** : ordre de quatre répliques, dictée de reconnaissance à choix ; ≥ 8 items de L4. ZH : tons lexicaux écrits, sandhi de nǐ hǎo entendu ; JA : voyelles longues ō/ū ; DE : /ʏ/ *Tschüss* vs /uː/ *du*.
6. **Je rejoue la rencontre** : échange guidé de trois formules, rappel différé ; aucun vocabulaire nouveau ; saluer, se présenter, prendre congé.
