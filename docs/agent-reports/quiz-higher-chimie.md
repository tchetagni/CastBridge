## Rejets corrigés
- Validation `import --dry-run` (python 3.12, le module `qb.gen` exige ≥ 3.12) : 0 rejet et 0 avertissement sur les 15 fichiers finaux. Les rédacteurs ont corrigé en cours de route des rejets typiques : choix quasi identiques après normalisation (signes et ponctuation ignorés), formulations « Les deux… »/« Tous les… », questions sans « ? ».
- Doublons inter-fichiers : après assemblage, 55 questions identiques (texte normalisé) ont été retirées (L1 : 23, L2 : 21, L3 : 11), y compris des doublons entre niveaux. Elles ont été remplacées par des compléments nouveaux dans les fichiers `-05`. Contrôle final : aucun doublon exact dans les 1 500 questions ; concaténation par niveau validée sans rejet.
- Les fichiers `-01` à `-04` ont donc parfois moins de 125 questions (116 à 125) ; la source Python des rédacteurs n'est pas versionnée, seuls les JSON le sont.

## Méthode
12 rédacteurs en parallèle (4 angles : définitions ; applications directes ; calculs/tendances ; pièges et laboratoire), puis dédoublonnage et compléments. Les calculs numériques ont été recalculés par script Python avant écriture (sauf quelques calculs triviaux faits à la main dans les compléments L1 et L2, recoupés par un contrôle rapide).

## Limites
- Contenu écrit par IA, non relu par un humain : tout est en statut `review`. Une relecture par un chimiste est indispensable (réponses uniques, distracteurs réellement faux, difficultés estimées).
- Les libellés `category` ne sont pas unifiés entre fichiers (36 libellés en L1, 43 en L2, 47 en L3 pour 25 sous-thèmes du programme) : formulations différentes d'un même sous-thème, pas de sous-thème hors programme. À normaliser à l'intégration si besoin.
- Répartition des sous-thèmes ≈ 4 % chacun par fichier principal ; les compléments `-05` ne couvrent pas tous les sous-thèmes. Aucun sous-thème n'excède 8 % d'un fichier.
- Les difficultés sont des estimations (L1 ≈ 30/30/20/13/7, L2 ≈ 28/31/21/13/7, L3 ≈ 30/30/20/12/8). Les lettres sont équilibrées à ±2 points de 25 %.
- Les `source` sont des familles de manuels génériques (Atkins, Clayden/McMurry, Skoog, Housecroft-Sharpe, etc.), sans titre ni page.
- Contrôle par `cells_report.py` et `quizbank.py check` (banque entière) non exécutés ici ; seuls les `import --dry-run` l'ont été.
