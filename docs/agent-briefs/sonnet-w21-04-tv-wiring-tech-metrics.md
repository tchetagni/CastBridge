## Objectif (autonome)
Le cœur fournit `TechMetrics`, les enregistreurs, `SendPolicy` (w21-01) et `Packer`, `Sealer`, `SealedOutbox`, `ChunkCodec`, `Receipt` (w21-01b). Règles du propriétaire (2026-10-04) : la TV reliée à Internet **sans** passerelle envoie elle-même ses statistiques **toutes les 12 h** ; synchronisée à un téléphone, elle lui **remet** un lot scellé **toutes les 4 h** quand il est disponible, par le **meilleur canal local** (réseau commun > Wi-Fi Direct > Bluetooth ; « La TV envoie en bluetooth la télémétrie si c'est le seul canal dispo pour la synchro ») ; c'est le téléphone qui envoie au serveur. **La TV n'envoie plus jamais de télémétrie par la passerelle Bluetooth vers le serveur** ; jamais rien pendant une partie Internet ni 30 s après. Le heartbeat garde son chemin.

## Étapes
1. **Rouge** (sortie collée) : `TvTeleSenderTest.neverThroughTheGateway`.
2. Points de mesure (`PlayProbe` → `SessionRecorder` ; `perf.*`, `link.*`, `sync.xfer`, `net.route.flips`) ; sonde nulle par défaut ⇒ tests de w20-05a verts sans modification.
3. `TvTech` : objet nul hors porte ; retrait du consentement ⇒ files vidées (évènements **et** lots scellés non remis).
4. `TvTeleSender` : `SendPolicy.decide` toutes les 5 min ; lot direct toutes les 12 h (voie Internet `direct` **seulement**) ; lot pour le téléphone toutes les 4 h ; scellement `Sealer` avec le jeton courant ; `SealedOutbox` ; accusé du chemin direct vérifié puis purge ; TV sans jeton ⇒ rien n'est scellé (hors POC).
5. `TeleHub` : la remise est **tirée par le téléphone** sur la route HTTP que `LinkPlanner` lui donne (réseau commun, groupe Wi-Fi Direct **déjà existant**, tunnel Bluetooth) ; plus basse priorité (cède à toute requête de copie, de télécommande, de passerelle) ; **suspendue** (réponse `503` + `Retry-After`) pendant une copie, une lecture vidéo, une partie (locale ou Internet) et 30 s après ; fenêtre ≤ 30 s et ≤ 64 Ko par remise, ≤ 1 remise / 15 min par téléphone ; lot marqué `HANDED(téléphone)` ; `POST /api/tele/receipts` : purge **seulement** sur `Receipt` valide (faux accusé compté, M-59) ; `pocMetrics` lu dans l'accusé ; évènements `tele.handoff` (canal `lan`/`wd`/`bt_api`/`bt_frames`, durée, octets, morceaux, reprises, temps suspendu) et `tele.receipt`.
6. **Vert** ; compilation du build verrouillé.
