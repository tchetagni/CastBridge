Agent cloud. Base `origin/integration/agents`. Branche `claude/license-admin`. Protocole `docs/COORDINATION.md` (rapport vivant `docs/agent-reports/license-admin.md`). Pas de PR, pas de main. **Tu n'as aucun accès au serveur** : tu écris le code, les migrations et les tests dans `backend/` ; le coordinateur déploie en préproduction (port 7091, base de test) avant toute bascule. Français, aucun secret dans le dépôt.
Lire : `backend/README.md` (administration `/admin`, sécurité, sauvegardes), `backend/src/main/resources/db/migration` (V1…V30 : **nouvelles migrations à partir de V50**, rétrocompatibles), `backend/src/main/java/castbridge/server/admin/*` (conventions des contrôleurs, CSRF, CSP stricte : aucun script ni style en ligne, thème sombre, français, utilisable sur téléphone), `docs/agent-briefs/trial-edition.md` (modèle de droits, licence, postes, portées de clés, ré-activation, transfert, console propriétaire), `docs/agent-briefs/activation-tools.md`, `docs/SERVER-STRATEGY.md`, `core/.../lots/Entitlement.kt` (branche `claude/trial-edition`).

## Décisions du propriétaire (à respecter)
- **Une clé de signature par outil** (bureau, téléphone propriétaire, serveur) ; la TV accepte toutes les clés autorisées ; **la portée de chaque clé limite ses pouvoirs : la clé du serveur ne peut ni transférer une licence, ni « tout ouvrir »** (elle émet essai, achats à la carte, abonnements, ré-activations). Règle commune : **identifiant de licence + décompte des postes**.
- Les applications se distribuent librement, **l'usage est soumis à l'autorisation du propriétaire** ; rien n'est gratuit sans clé ; essai délivré sous son contrôle (**émission manuelle par défaut**, automatique désactivée).
- Contenus additionnels : **à la carte ou par abonnement** ; aucun prix ni prestataire de paiement imposé (champs prévus, rien d'autre).
- Phase hors ligne jusqu'à 1 an : le serveur doit **importer** les journaux émis hors ligne par le bureau et le téléphone et se **réconcilier** avec eux.

## À livrer (module « licences » dans `backend/`)
1. **Modèle de données** (migrations Flyway ≥ V50, contraintes d'unicité, index, clés étrangères) : `client` (nom, contact, notes, **minimum de données personnelles**), `produit`/`bouquet` (identifiant, type à la carte ou abonnement, lots couverts, durée, champs de tarif **vides** : prix hors périmètre), `licence` (`licenseId` unique, client, droits, début, fin, **nombre de postes**, état : active, suspendue, révoquée, expirée), `poste` (licence, **code d'appareil**, empreintes de facteurs hachées, première/dernière vue, état), `emission` (jeton émis : `kid`, nonce, expiration, émetteur, canal, empreinte du jeton ; **jamais la clé**), `transfert` (ancien/nouveau poste, qui l'a signé, plafond), `revocation`, `journal d'audit`.
2. **Règles métier testées** : création/modification/suspension/révocation/prolongation d'une licence ; **décompte des postes sûr en concurrence** (transactions + contrainte : jamais plus de postes que autorisé, même sous requêtes simultanées) ; **ré-activation** du même matériel sans consommer de poste ; **transfert** (plafond par licence, par défaut 2 par an, réglable) **enregistré** quand il vient du registre importé (le serveur ne signe jamais un transfert) ; expiration et période de grâce ; idempotence des émissions.
3. **Émission par le serveur** : `ActivationSigner` (interface) implémenté avec l'`ActivationIssuer` de `core` dès que le format filaire de `claude/trial-edition` est poussé (`docs/ACTIVATION-FORMAT.md`) ; **portée limitée de la clé serveur appliquée dans le code et testée** (refus de tout transfert et de tout « tout ouvert » avec la clé serveur) ; clé lue dans le dossier des secrets (jamais dans l'image ni les journaux).
4. **Interface d'administration** (dans `/admin`, mêmes conventions de sécurité) : **liste des licences** (recherche, filtres par état/client/bouquet/expiration, tri, export CSV) ; **fiche licence** (droits, postes avec première/dernière vue et état, historique complet, boutons : suspendre, révoquer, prolonger, changer le nombre de postes, ajouter un bouquet, **libérer un poste**, réémettre une activation) avec **confirmation** et motif obligatoire pour toute action destructrice ; **recherche par code d'appareil** ; **formulaire d'émission** (code d'appareil + licence → activation à copier/télécharger/QR, valeurs validées) ; **tableau de bord** (licences actives, expirant sous 30 jours, postes utilisés, essais délivrés, doublons suspects) ; **catalogue de bouquets** ; **journal d'audit** consultable et filtrable ; **registre** : page d'**import/export** du fichier de licences **signé** pour synchroniser avec les outils hors ligne, avec **rapport de réconciliation** (conflits : même poste émis par deux outils, dépassement de postes, licences inconnues) et décision manuelle.
5. **API d'administration** (`/api/v1/admin/licenses/**`, jeton Bearer existant) pour scripts : mêmes fonctions, JSON, pagination, erreurs claires. **Routes publiques minimales** pour la TV/le téléphone (aucune en phase hors ligne ; spécifie `GET /api/v1/revocations` signée et `GET /api/v1/entitlements/me`, derrière l'authentification d'appareil existante, désactivées par un interrupteur).
6. **Sécurité robuste** : rôles (`propriétaire`, `support` lecture + réémission, `lecture seule`) appliqués côté serveur et testés par matrice ; **double authentification TOTP** pour le rôle propriétaire (sans service externe) ; verrouillage et limites de débit existants conservés et étendus ; **journal d'audit chaîné par empreintes** (altération détectable) avec vérification ; validation stricte de toutes les entrées ; pas de secret ni de code d'activation complet dans les journaux (seulement l'empreinte) ; protection CSRF/CSP/XSS ; **droit à l'effacement et export** des données d'un client (RGPD) sans casser le décompte (les postes sont anonymisés, pas supprimés) ; sauvegarde incluse dans `backup.sh` (liste ce qu'il faut ajouter) et **procédure de restauration testée**.
7. **Détection d'abus** : même code d'appareil vu depuis plusieurs téléphones ou IP, postes au-dessus du quota, rafale d'émissions, transferts répétés ; alertes visibles au tableau de bord (aucun blocage automatique sans décision du propriétaire).
8. **Tests** : JUnit/MockMvc + base de test, migrations sur base vide et sur une copie des schémas V1–V30, **concurrence** sur les postes, matrice des rôles, chaîne d'audit, portée de la clé serveur, import de registre avec conflits, idempotence. `cd backend && ./mvnw test` (si le build Maven est impossible dans ton environnement, dis précisément ce qui n'a pas pu être exécuté).
9. **Déploiement sûr** (à documenter dans `docs/LICENSE-ADMIN.md`) : sauvegarde avant migration, migrations réversibles ou au moins rétrocompatibles, interrupteur de fonctionnalité, préproduction, retour arrière ; mémoire de la JVM (limite de 512 Mo) : pas de requêtes lourdes, pagination partout.
10. Docs : `docs/LICENSE-ADMIN.md` (guide du propriétaire : créer une licence, activer une TV, libérer un poste, importer le registre hors ligne, révoquer), `docs/HANDOFF.md`.

## À ne pas faire
Aucun paiement, aucun prix, aucun accès au serveur ni à sa configuration partagée, aucune clé privée dans le dépôt, aucune donnée réelle de client dans les tests.
