# Parcours critiques CastBridge ↔ CastBridge-TV : la liste que la barrière anti-régression rejoue (W14, 2026-10-02)

> Source : `docs/coordination/DESIGN-W14-BARRIERE-ANTI-REGRESSION-2026-10-02.md` § 1. **Aucun secret ici** (le PIN de la TV se lit sur son écran ; jamais dans un fichier).
> Un parcours est **critique** quand sa casse a atteint, ou peut atteindre, le propriétaire sur ses vrais appareils (Samsung S21+ Android 14 ; TV GaiaOS 32 bits 1280×720 ; LAN 192.168.0.x avec isolation Mac → TV). Chaque ligne est un **contrat observable** : préconditions, étapes, résultat attendu **sur les deux appareils**, gravité, et **où** il se vérifie.

## Légende

| Colonne « Où » | Sens | Qui / quoi |
|---|---|---|
| **JVM** | rejoué en processus par le harnais de parcours du cœur (`CT/journey/*`, cahiers w14-01…04) : vraie `ReceiverServer` NanoHTTPD sur port 0 + `LinkDriver`/`FakeTv` Bluetooth sur flux en mémoire + `TransferClient` ; horloge et aléa injectés | CI et porte locale, < 2 min |
| **ÉMU** | suite de fumée `tools/smoke/` contre la **TV émulée** (`cbconnect_tv`, Android TV 34 arm64 : l'APK TV contient la tranche `arm64-v8a`) et le téléphone (émulateur `cbconnect_phone` ou téléphone réel) ; ou contre la **fausse TV du Mac** (`FakeTvMain`, w14-10) pour les cas où la TV doit être « sacrifiée » (réinstallation, PIN changé, essai) | coordinateur, < 10 min |
| **ADB** | téléphone réel du propriétaire par `adb` (lecture : `logcat`, `dumpsys notification`, `uiautomator dump`, `screencap` ; action : `am start`, `input`) ; **jamais** d'effacement de données sans accord | coordinateur avec le téléphone branché (`stay_on_while_plugged_in=3`) |
| **TVro** | vraie TV **en lecture seule** : `GET /api/{hello,info,activation,library,transfer/state,apk,connections,screenshot}` par le relais `nc` du téléphone, `ssh -p 2223 cbdev status` ; aucun POST, aucune installation, aucun PIN faux (verrou 60 s) | coordinateur, sans toucher l'état de la TV du propriétaire |
| **H** | seul un humain devant la vraie TV peut le confirmer : `docs/test-plans/CHECKLIST-HUMAINE-LIVRAISON.md` | propriétaire ou testeur, ≤ 15 min par livraison |

Gravité : **S1** = bloque l'usage de base (copie, liaison, activation) ; **S2** = fonction majeure dégradée, contournement possible ; **S3** = confort. **Régression** = numéro de `docs/REGRESSIONS.md` (R-01…R-05 = les cinq cas du propriétaire des 2026-10-01/02).

Préfixes de code : `C/` = `android/core/src/main/kotlin/castbridge/core/`, `CT/` = `android/core/src/test/kotlin/castbridge/core/`, `R/` = `android/receiver/src/main/kotlin/castbridge/receiver/`, `S/` = `android/sender/src/main/kotlin/castbridge/sender/`.
