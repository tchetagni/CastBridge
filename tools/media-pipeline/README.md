# media-pipeline

Chaîne de préparation de la production multimédia (voir `docs/MEDIA-PIPELINE.md`). Aucun appel réseau, aucun secret. `python3 mp.py --help`. Tests : `cd tests && python3 -m unittest test_pipeline`.
`templates/` : `pricing.json` et `request-policy.json` (à copier et remplir), `registry/` (registres vides), `legal/` (gabarits à faire valider), `castbridge-content/` (AGENTS.md, .claude/CLAUDE.md, lot de travail, arrêt budget).
