Émettre une activation

Aucune clé de signature serveur n'est installée : l'émission est impossible (voir docs/LICENSE-ADMIN.md).

Format :

Collez la demande d'appareil (texte « code=… k=… factor=… » affiché par l'appareil ou transmis par Bluetooth) : le code seul ne suffit pas à construire l'activation. Elle est vérifiée en entier (le code doit dériver des facteurs). Le même matériel garde son poste ; un nouveau matériel en prend un.
