Activation hors ligne (TV)

Générer un jeton d'activation

La TV affiche un code machine (dérivé de son adresse MAC). Saisissez ce code pour obtenir le jeton d'activation, à donner à l'utilisateur pour qu'il le saisisse sur la TV. Aucun accès réseau à la TV n'est nécessaire.
